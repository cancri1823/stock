📊 投資戰情與選股整合平台 雙系統隔離版

📖 整合平台使用說明

本網頁將「全球原物料與匯率戰情室」與「選股 · 四維聯動」整合於單一介面，並透過獨立的 <iframe srcdoc> 沙盒隔離技術，確保兩套系統的深淺色主題、JavaScript 變數、IndexedDB、localStorage 與 API 呼叫完全互不干擾。

🧭 1. 系統總覽：雙系統的定位與互補關係

🌐 全球原物料與匯率戰情室（由上而下：總經環境）

專注於追蹤市場風險情緒（VIX）、能源與原物料（WTI/Brent 原油、金、銀、銅、鐵礦砂）以及主要匯率（USD/JPY/CNY/EUR 對台幣）。

協助您在每天盤前或盤後掌握全球資金流向、通膨與原物料成本變化，並記錄當日戰略觀察筆記。

📈 選股 · 四維聯動（由下而上：個股基本面與買賣點）

串接 FinMind 台股資料庫，從基本面（40分）、估值（20分）、籌碼面（20分）與技術面（20分）四個維度對台股個股進行機械式評分。

互補運用：先透過「戰情室」確認大環境（如 VIX 是否飆高、匯率與原物料趨勢），再到「四維聯動」篩選體質優良且處於合理買點的個股。

🌐 2. 「全球原物料與匯率戰情室」操作說明

  • 本地快取 系統內建 IndexedDB 資料庫，首次開啟會自動載入預設範例數據，所有新增或修改的每日紀錄都會即時儲存在您的瀏覽器中。
  • 雲端同步 若需跨裝置同步，可點擊右上角 「⚙️ 雲端設定」 輸入您的 Google OAuth Client ID，再點擊 「☁️ 連結 Google 雲端硬碟」，資料將以 war_room_data.json 儲存於您的雲端硬碟根目錄。
  • 新增與編輯 點擊 「➕ 新增 / 編輯當日數據」 可填寫或更新當日各項報價、漲跌幅與看盤筆記；點擊下方歷史表格任一列可快速切換上方看板顯示的日期。
  • 資料匯出 點擊 「📥 匯出 CSV」 可將所有歷史紀錄匯出為 UTF-8 CSV 檔案，方便使用 Excel 進行進階分析或備份。

📈 3. 「選股 · 四維聯動」操作說明

  1. FinMind Token 建議至 FinMind 官網註冊並複製 API Token 貼入上方欄位（有 Token 每小時可呼叫 600 次，未登入則為 300 次）。
  2. 加入股票 在輸入框輸入 4 碼台股代號或名稱（如 2330 或 台積電）並按「加入」，清單會自動保存於瀏覽器。
  3. 四維評分 設定「基本面可未通過項數」（預設 0 最嚴格，可放寬至 1~2 項，或勾選「不淘汰，全部評分」），點擊 「開始篩選」。總分 75 以上為「強烈關注」、60 以上「關注」、45 以上「觀察」。
  4. 快照與比對 每次篩選完成會自動儲存當日快照。不同日期各篩選一次後，可切換至內部的 「比對」 頁籤，比較「新進榜」、「掉出榜」、「評級升降」與「股價變化」。
  5. JSON 備份 點擊 「匯出 JSON」 可備份當次完整分析結果；更換瀏覽器時可在「比對」頁籤匯入舊的 JSON 檔案接續追蹤。

🔒 4. 資料儲存與隱私安全說明

  • 純瀏覽器端運算，無後端伺服器：本整合頁面為純靜態 HTML 檔案，所有計算、篩選與圖表渲染皆在您的本機瀏覽器內完成。
  • 憑證與資料不外流：您的 FinMind Token、Google OAuth Client ID、自選股清單與歷史快照僅儲存在您本機的 localStorage 與 IndexedDB 中，不會傳送至任何第三方伺服器（僅在您主動觸發同步或篩選時，直接向 Google Drive API 或 FinMind API 發送請求）。
  • 投資風險提示：四維聯動分數係依固定財務與技術指標機械式計算，僅供研究與篩選參考，不構成任何投資建議。
